# План проверки Deep Research

Дата: 2026-10-08, Europe/Moscow. Базовая спецификация: 1.0.
План записан до экспериментального кода. Исходный research-отчёт не редактируется.

Проверяем реальный генератор, библиотеки и технические предпосылки. Обработчика XLSX ещё нет:
ни один результат эксперимента не означает успешную приёмку полного конвейера очистки.
Все эксперименты выполняются локально, без сетевых запросов. Зависимости только для исследования.

Решения заказчика после чтения Research:

* Телефон — только структура; внешние сайты не опрашивать. Регион RU/валидный диапазон не gate.
* Спорный регистр имени не изменять; помечать для проверки.
* NFC разрешён для обработанных имён и сравнения дублей; исходник сохраняется.

После первых наблюдений дополнительно подтверждено:
все латинские имена сохранять и помечать; основной телефон при однозначности извлекать,
всё дополнительное сохранять в аудите и проблемах. Эти уточнения внесены до финального прогона.

| ID | Эксперимент | Заранее установленное ожидание |
|---|---|---|
| EXP-01 | Извлечь все полевые таблицы из Research, связать строку с исходным текстом | Не заменять `...`, `<blank>` и типовые описания догадками; отдельно учитывать конкретные примеры |
| EXP-02 | Сравнить удаление всех нецифр, parse(raw), matcher и проверку чистого кандидата | Комментарий/добавочный не должен становиться частью телефона; permissive parse не заменяет extraction |
| EXP-03 | Сравнить структуру и phonenumbers metadata | +7 KZ и незанятый диапазон могут различаться; это диагностика исследовательского стенда |
| EXP-04 | Числовые даты DMY и календарь Python | 09/03/2026 = 2026-03-09; несуществующие даты дают отказ без коррекции |
| EXP-05 | dateparser default, strict, strict + allowlist | Strict сам по себе не доказывает отсутствие догадок; relative base фиксирован на 2026-10-08 12:00 |
| EXP-06 | XLSX serial 59/60/61, обе epoch, General/date format, time-only, formula | Raw XML нужен для serial 60; General не доказывает дату; формулы не вычисляются |
| EXP-07 | Имена, title(), NFC/NFD/NFKC, ZWSP, NaN | Спорный регистр/невидимые символы сохраняются; NFC связывает канонически эквивалентные имена |
| EXP-08 | Mutation-based данные + Hypothesis | Форматирование чистого значения сохраняет его смысл; round-trip календаря; сохранность raw при отказе |
| EXP-09 | Группы дублей из существующего manifest | Первая запись остаётся; source-only не проблема; участники конфликтной группы все диагностируются |
| EXP-10 | Base64 в ячейках XLSX, типы формул, длина 32767/32768 | Побайтное восстановление исходника; формулы представлены как текст; обрезка запрещена |

Материалы: `run_experiments.py` создаёт новый каталог с `results.json`, `coverage.json`,
`tables.xlsx`, XLSX-пробами и markdown-отчётом. Существующий каталог не перезаписывается.
В результатах разделены наблюдения библиотек, проверяемые ожидания и нерешённые вопросы.
Подробный итог методологии хранится в `EXPERIMENT_REPORT.md` после запуска.
